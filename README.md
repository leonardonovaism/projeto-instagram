📱  Projeto Instagram — Interface de Login

Projeto desenvolvido com o objetivo de recriar a interface de login do Instagram, utilizando HTML5 e CSS3, com foco na aplicação prática de conceitos de Flexbox, estruturação de páginas e estilização de interfaces.

📚 Projeto desenvolvido durante meus estudos de desenvolvimento web.

🎯 Objetivo
Reproduzir visualmente a interface de login do Instagram, buscando praticar a construção de layouts utilizando HTML e CSS.

O projeto foi desenvolvido como exercício prático para consolidar conhecimentos de:
- Estruturação HTML
- CSS
- Flexbox
- Posicionamento de elementos
- Organização visual
- Responsividade
- Reprodução de interfaces
- 
🛠️ Tecnologias utilizadas
HTML5
CSS3
Flexbox

📌 Observação
Este projeto possui finalidade educacional, desenvolvido para fins de estudo e prática de desenvolvimento web.

A interface apresentada é uma recriação baseada visualmente na página de login do Instagram e não possui qualquer vínculo oficial com a Meta ou com o Instagram.
